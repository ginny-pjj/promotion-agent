## 三、实现思路

```text
输入文本
   ↓
抽取层（extractor.py）     ← 当前用正则；后续可换大模型
   ↓
规则层（validator.py）     ← 金额、笔数、日期、重复、未匹配账号
   ↓
人工确认层（human_review.py）← 有异常 → 生成人工确认单，指派负责人
   ↓
输出层（excel_writer + report）← 测试表副本 + 汇报
```

原则：

- 大模型只做「理解」，不做「裁决」
- 金额和异常判定永远用 Python 规则
- 原表只读，只写测试副本
- 有问题必须人工确认

面试可讲：`validator.py`、`excel_writer.py`、`human_review.py`

## 四、遇到的问题

| 问题 | 处理 |
|---|---|
| Excel 在 VS Code 打开乱码 | `.xlsx` 需用 Excel/WPS；程序用 openpyxl |
| 模板文件名变成 `.xlsx.xlsx` | 修正为正确后缀 |
| Excel 写入报错 | 给 Cell 赋 `.value` |
| 账号差一字匹配失败 | 增加 `unmatched_account` 转人工 |
| 企业微信建内部群失败 | 演示阶段用人工确认单手动发送 |
| 文件夹看起来杂乱 | 清理缓存/输出；文档进 `docs/`，测试进 `tests/`，视频进 `demos/` |

## 六、AI 生成了什么，我做了哪些检查 / 修改

**AI 辅助：** 项目骨架、网页演示、人工确认流转、文档草稿。

**我做的检查与修改：**

1. 确认金额/异常必须由代码判定，不能交给 AI 拍板  
2. 用真实飞书表格实测匹配与写入  
3. 修 Excel 写入与文件名问题  
4. 决定先做「异常 → 人工确认」，暂不接企业微信群  
5. 选定演示用例 A（笔数/日期）+ C（账号名）
