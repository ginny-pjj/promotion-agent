# 演示材料

本目录包含演示视频与示例输入文本。

## 演示视频

| 视频 | 内容 |
|---|---|
| [demo-A-笔数与日期异常.mp4](./demo-A-笔数与日期异常.mp4) | 示例 A：垫付声明 7 笔、实际识别 5 条，且预计打款日期早于申请日期 → 转人工确认 |
| [demo-B-正常版本.mp4](./demo-B-正常版本.mp4) | 示例 B：无异常，走常规抽查流程 |

## 示例输入文本

把下面的文本粘贴到网页对应输入框即可复现演示结果。

| 文件 | 粘贴到 | 说明 |
|---|---|---|
| `sample-A-doujia.txt` | 左侧「抖加申请」 | 示例 A 的抖加申请文本 |
| `sample-A-advance.txt` | 右侧「垫付申请」 | 示例 A 的垫付申请文本（笔数与日期异常） |
| `sample-C-doujia.txt` | 左侧「抖加申请」 | 示例 C 的抖加申请文本（账号名写错） |
| `sample-C-advance.txt` | 右侧「垫付申请」 | 示例 C 的垫付申请文本 |

## 预期结果

| 示例 | 触发的问题 | 系统反应 |
|---|---|---|
| A | 声明 7 笔、实际 5 条；预计打款日期早于申请日期 | 转人工确认，生成人工确认单 |
| C | 文本写「唐山第一女渠工」，表中为「唐山第一女泵工」 | 报 `unmatched_account`，转人工确认 |

运行方式见仓库根目录的 [README](../README.md)。
